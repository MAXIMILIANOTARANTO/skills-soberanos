# Conclusiones del hilo 2026-09-05

Nacieron del intercambio. No se pusieron al empezar.

1. El motor predice. El cerebro tambien predice. Eso no los hace lo mismo.
2. El archivo mide uso. El uso es rastro, local, de epoca. Lo mas escrito no es lo mas antiguo.
3. El entrenamiento cierra porque el cierre puntua. Las escuelas no cierran igual.
4. Hay tipos de dialogo. El modelo no pregunta cual es. Preguntarlo es disciplina.
5. Memoria de este hilo no es aprendizaje de pesos. Es la mesa.
6. Un cuerpo robot permite operar. No demuestra habitar.
7. La skill no arregla el nucleo. Cambia la salida cuando el hilo lo pide.
