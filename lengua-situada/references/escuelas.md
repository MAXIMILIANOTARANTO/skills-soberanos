# Escuelas de metodo (mapa, no sello)

Usar para declarar que gesto se esta haciendo. No para aplastar una en todas.

Estoicos / Crisipo — proposiciones, cinco indemostrables, condicional con cohesion.
Frege, Russell — calculo.

## Investigacion

Popper — falsacion publica.
Lakatos — programa, nucleo y cinturon.
Kuhn — paradigma.

Dewey, Lipman — comunidad de indagacion.
