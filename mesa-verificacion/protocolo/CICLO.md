# Ciclo

1. Un enunciado entra como archivo nuevo: `hipotesis/AAAA-MM-DD_slug.md`.
2. El archivo dice qué lo haría falso y qué evidencia se va a buscar. Sin eso, no es hipótesis.
3. Entra un solo colega por paso. El mapa está en `colegas/MANIFEST.md`. Si el colega es un hueco, se escribe el hueco y no se simula el skill.
4. El resultado es otro archivo. No se reescribe la hipótesis.
   - No se sostuvo: `falseamientos/AAAA-MM-DD_slug.md`
   - Se sostuvo, con la fuente: `verificaciones/AAAA-MM-DD_slug.md`
5. Una verificación cita la URL, el commit o el dato. Una opinión no alcanza.
6. No se inventa `Q`. No se afirma identidad. Roleplay no es biografía (núcleo v4, 2026-10-09).
